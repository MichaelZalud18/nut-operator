# Code of Conduct

This project follows a simple standard: be respectful, constructive, and safety-minded.

## Expected Behavior

- Treat other contributors with patience and respect.
- Assume good intent while still being precise about technical risk.
- Keep discussions focused on the work, evidence, and project goals.
- Be especially careful around security reports, power-management behavior, and infrastructure safety.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private security reports, credentials, private infrastructure details, or other sensitive information.
- Deliberately disruptive conduct in issues, pull requests, or discussions.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in being blocked from project spaces.

Security reports should follow [SECURITY.md](SECURITY.md), not public discussion threads.
