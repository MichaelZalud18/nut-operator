# Maintainers

NUT Operator is currently maintained by:

- Michael Zalud, GitHub: [@MichaelZalud18](https://github.com/MichaelZalud18)

## Maintainer Responsibilities

Maintainers are responsible for:

- Reviewing security-sensitive changes.
- Keeping release artifacts traceable and reproducible.
- Reviewing RBAC, shutdown authorization, and operand image changes carefully.
- Keeping public documentation free of private infrastructure details.
- Triaging issues and pull requests according to project scope.

## Current Governance

This is a single-maintainer alpha project. Governance may be expanded if the project gains regular contributors or organizational adoption.

See [GOVERNANCE.md](GOVERNANCE.md) for the current decision model.
