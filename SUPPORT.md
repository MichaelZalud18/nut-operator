# Support

NUT Operator is pre-1.0 alpha software.

## Getting Help

Use GitHub issues for:

- Bug reports.
- Feature requests.
- Documentation gaps.
- Questions about supported API behavior.

Do not include credentials, kubeconfigs, private IP addresses, private hostnames, or sensitive logs in issues.

For vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Production Use

Production use is not recommended until the project has:

- Published, signed, and scanned release images.
- SBOM and provenance attestations.
- Resolved known dependency vulnerabilities.
- Documented upgrade and compatibility policy.
- Validated end-to-end shutdown behavior in a dedicated test environment.
